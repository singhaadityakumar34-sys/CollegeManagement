# Student Management System

## Project Overview

Student Management System is a web-based application developed using Python and Django.

The system is designed to manage student records digitally. It provides features for adding, viewing, editing, deleting, searching and filtering student information.

## Technologies Used

- Python
- Django
- SQLite
- HTML
- CSS
- JavaScript
- Pillow

## Main Features

1. User Login and Logout
2. Dashboard
3. Student Registration
4. Student Photo Upload
5. Date of Birth Management
6. View Student Details
7. Edit Student Details
8. Delete Student Records
9. Search Students
10. Filter Students
11. Django Admin Panel
12. Responsive User Interface

## Student Information

The system stores:

- Student ID
- Name
- Email
- Phone Number
- Course
- Semester
- Gender
- Session
- Date of Birth
- Student Photo
- Address
- Registration Date
